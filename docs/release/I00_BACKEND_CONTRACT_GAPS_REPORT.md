## Delivered contracts

### General public pages

`ContentEntry.Kind.PAGE` extends the accepted B08 content domain so pages such as About can be managed through the audited content Admin and consumed from the existing public content API.

### Site configuration

`SiteConfiguration` provides the public operator-managed business/trust/footer/SEO values that previously existed only as frontend constants. The public endpoint is fail-closed when no row is configured and never exposes payment-provider credentials.

Public contract:

- `GET /api/v1/site/config/`

### Homepage blocks

`HomepageBlock` provides ordered, enabled/disabled operator-managed homepage content and merchandising slots without turning layout/CSS/application behavior into CMS data.

Public contract:

- `GET /api/v1/site/home/`

### Contact intake

`ContactMessage` provides a real persisted contact workflow. Public creation is CSRF-protected, rate-limited and validated; staff workflow state is managed in audited Admin.

Public contract:

- `POST /api/v1/contact/messages/`

## Admin / audit boundary

- Content/public-page mutations remain staff-only and audited.
- Site configuration is singleton-style, non-deletable through Admin and audited.
- Homepage block create/update/delete operations are audited.
- Contact sender/message fields are immutable in Admin; staff may only update workflow status, which is audited.
