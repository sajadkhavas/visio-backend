## Owner-approved public repository exception

Original architecture preference: `visio-backend` private.

Actual repository state at closure: `public`.

Owner decision on 2026-09-03: **public visibility is accepted and is not a B00 blocker**.

Safety invariants that remain mandatory despite public visibility:

- no secrets, API keys, passwords, production `.env`, private keys or production credentials may be committed;
- `.env.example` must remain non-secret example configuration only;
- secret-sanity CI remains mandatory;
- production settings remain fail closed;
- deployment credentials remain environment/server/secret-store managed;
- any future sensitive operational document must not be committed merely because the repository is owner-approved public.

The owner may later make the repository private without changing the B00 acceptance outcome.

## Truth boundary

B00 is foundation only. It does not implement final authentication policy, customer accounts, addresses, catalog, pricing, inventory, cart, wishlist, checkout, shipping, orders, payment, content/search authority or notifications. Those belong to B01–B10.
