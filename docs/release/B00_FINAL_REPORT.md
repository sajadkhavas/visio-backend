## Production HSTS boundary

B00 does not prematurely enable HSTS `includeSubDomains` or preload. Django warns that HSTS configuration can create serious operational problems when enabled without a proven domain-wide HTTPS policy. `security.W005` and `security.W021` are therefore the only explicitly deferred deployment warnings until R00/S00 freezes DNS/TLS/subdomain ownership. Every other deployment warning/error remains blocking in CI.

## Truth boundary

B00 is foundation only. It does not implement authentication policy, customer accounts, addresses, catalog, pricing, inventory, cart, wishlist, checkout, shipping, orders, payment, content/search authority or notifications. Those belong to B01–B10.
